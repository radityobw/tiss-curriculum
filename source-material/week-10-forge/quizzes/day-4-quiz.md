### Q1
**Type:** Multiple Choice
**Question:** Dalam CSS Box Model, apa perbedaan utama antara Margin dan Padding?
- [x] A. Margin digunakan untuk mengatur jarak di LUAR elemen (memisahkan elemen dari sekitarnya), sedangkan Padding mengatur jarak di DALAM garis batas (*border*) elemen (memisahkan konten dengan bingkainya).
- [ ] B. Margin selalu memiliki properti transparansi warna, sedangkan Padding selalu mengikuti warna *background* dasar situs web secara mutlak.
- [ ] C. Margin digunakan untuk mengukur bobot ukuran file memori RAM, sedangkan Padding mengukur koordinat lokasi resolusi pixel.
- [ ] D. Keduanya memiliki fungsi yang sama persis dan saling menimpa satu sama lain saat proses perenderan *browser*.

### Q2
**Type:** True/False
**Question:** Jika kita mengubah gaya (CSS) atau tata letak HTML melalui tab *Elements* di *Developer Tools* (F12), perubahan tersebut akan tersimpan permanen di server dan tetap ada saat halaman dimuat ulang (*Refresh*).
**Answer:** False

### Q3
**Type:** Short Answer
**Question:** Di dalam *Developer Tools*, *tab* apa yang berfungsi untuk memantau pertukaran data (*HTTP Request/Response*) antara peramban (*browser*) dan server?
**Answer:** Tab Network.

### Q4
**Type:** Short Answer
**Question:** Di dalam CSS, *selector* apa (yang dinotasikan dengan simbol pagar `#`) yang digunakan untuk menargetkan satu elemen unik secara spesifik di halaman HTML?
**Answer:** ID Selector.

### Q5
**Type:** Short Answer
**Question:** Sistem tata letak (*layout*) modern di CSS apa yang sangat fleksibel untuk menyejajarkan konten di dalam sebuah penampung (*container*), menggantikan metode lama seperti *float* atau tabel?
**Answer:** Flexbox (Flexible Box).
