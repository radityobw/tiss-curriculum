### Q1
**Type:** Multiple Choice
**Question:** Bagaimana terminal Linux menangani perintah `mv` ketika memindahkan file ke direktori (jalur target) yang sama persis dengan tempat asal file tersebut berada?
- [x] A. Perintah tersebut berfungsi sebagai pembaharuan atau penggantian nama file (*Rename*).
- [ ] B. Terminal akan langsung menghapus file tersebut secara permanen.
- [ ] C. Terminal akan menampilkan *error* dan proses akan terhenti (*crash*).
- [ ] D. Direktori akan terkunci dan membutuhkan hak akses administrator khusus.

### Q2
**Type:** True/False
**Question:** Jika perintah `rm laporan.txt` dijalankan secara langsung di terminal, dokumen tersebut akan otomatis masuk ke keranjang sampah (*Recycle Bin*) sehingga dapat dipulihkan kapan saja.
**Answer:** False

### Q3
**Type:** Short Answer
**Question:** Perintah singkat manakah yang sering digunakan di Linux untuk membuat sebuah file teks kosong tanpa harus masuk ke dalam antarmuka *text editor*?
**Answer:** touch.

### Q4
**Type:** Short Answer
**Question:** Opsi atau bendera (*flag*) apa yang wajib ditambahkan pada perintah `cp` agar terminal dapat menyalin sebuah direktori secara utuh beserta seluruh *file* dan subdirektori di dalamnya?
**Answer:** -r (Recursive).

### Q5
**Type:** Short Answer
**Question:** Perintah apa yang digunakan untuk mencetak/membaca seluruh isi teks sebuah file langsung ke layar terminal?
**Answer:** cat (Concatenate).
