### Q1
**Type:** Multiple Choice
**Question:** Mengapa dokumen standar internet diterbitkan dengan penamaan RFC (*Request for Comments*)?
- [x] A. Karena pada masa penciptaan internet, para ilmuwan mengundang diskusi dan perbaikan (komentar) dari ilmuwan lain secara terbuka ketimbang mendikte secara otoriter.
- [ ] B. Karena dokumen tersebut masih berupa konsep (draft) dan belum pernah disahkan sebagai standar baku hingga hari ini.
- [ ] C. Karena RFC dibuat khusus untuk menampung keluhan pengguna internet.
- [ ] D. Singkatan RFC sebenarnya merujuk pada *Randomly Formatted Code*, bukan *Request for Comments*.

### Q2
**Type:** True/False
**Question:** Jika sebuah CVE memiliki CVSS Score 9.8 (Critical), tim Blue Team (pertahanan) dapat menunda perbaikan tersebut hingga minggu depan asalkan server belum diserang.
**Answer:** False

### Q3
**Type:** Short Answer
**Question:** Jika seorang peretas mampu menjalankan kode atau program berbahaya di server korban dari jarak jauh, kerentanan mematikan ini dikenal dengan singkatan apa?
**Answer:** RCE (Remote Code Execution).

### Q4
**Type:** Short Answer
**Question:** Bagian krusial manakah dalam sebuah *CVE Advisory* yang harus diperiksa pertama kali oleh SysAdmin untuk memastikan apakah server yang mereka gunakan ikut terdampak?
**Answer:** Affected Versions (atau Affected Products).

### Q5
**Type:** Short Answer
**Question:** Apa kepanjangan dari lembaga pembuat standar internet (IETF) yang merilis dokumen RFC resmi?
**Answer:** Internet Engineering Task Force.
