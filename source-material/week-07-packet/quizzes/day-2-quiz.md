### Q1
**Type:** Multiple Choice
**Question:** Apa perbedaan utama hierarki *file system* Linux dibandingkan dengan sistem *drive letter* di Windows (seperti `C:\` dan `D:\`)?
- [ ] A. Linux mengelompokkan foldernya semata-mata dengan lambang bintang dan seru.
- [x] B. Di Linux, semuanya berawal dari satu direktori induk tertinggi yang disebut "Root" dan dilambangkan dengan simbol `/`.
- [ ] C. Linux sepenuhnya tak mengenal hierarki folder; seluruh aplikasinya berbaur acak dalam satu folder desktop.
- [ ] D. OS ini memanggil partisi pertamanya sebagai `/Drive1:\`.

### Q2
**Type:** True/False
**Question:** Di Linux, setiap pengguna dilarang memodifikasi atau membuat file baru di dalam direktori `/home/user` milik mereka sendiri karena dapat merusak sistem.
**Answer:** False

### Q3
**Type:** Short Answer
**Question:** Perintah (*command*) dasar apa yang digunakan untuk mengecek lokasi direktori tempatmu berada saat ini di Terminal?
**Answer:** pwd (Print Working Directory).

### Q4
**Type:** Short Answer
**Question:** Karakter apa yang diletakkan pada awal nama sebuah file atau folder agar file tersebut secara otomatis tersembunyi (*hidden*) di Linux?
**Answer:** Tanda titik (`.`).

### Q5
**Type:** Short Answer
**Question:** Perintah apa yang digunakan untuk berpindah mundur (naik satu tingkat) ke direktori induk (*parent directory*)?
**Answer:** `cd ..` (Perintah cd diikuti spasi dan dua tanda titik).
