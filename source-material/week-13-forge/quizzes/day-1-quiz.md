### Q1
**Type:** Multiple Choice
**Question:** Mengapa kita membutuhkan sistem *Database* (seperti SQL) dibandingkan hanya menyimpan data di dalam variabel *array* atau memori internal *Node.js*?
- [x] A. Penyimpanan variabel *Node.js* bersifat sementara (hilang jika server di-*restart*), sedangkan database menyimpan data secara permanen di dalam *storage* komputer.
- [ ] B. Karena database secara otomatis akan memblokir serangan siber dari *hacker* tanpa perlu konfigurasi apapun.
- [ ] C. Database mewajibkan kompatibilitas CSS agar aplikasi berjalan lebih cepat di sisi peramban pengguna.
- [ ] D. Node.js tidak bisa menyimpan data dalam bentuk *array* atau *object*.

### Q2
**Type:** True/False
**Question:** Untuk memperbarui atau memodifikasi data di dalam tabel SQL, kita harus menggunakan perintah awalan `SELECT`.
**Answer:** False

### Q3
**Type:** Short Answer
**Question:** Simbol apakah yang digunakan setelah perintah `SELECT` untuk mengambil **seluruh kolom** di dalam tabel database?
**Answer:** Bintang (Karakter Asterisk `*`).

### Q4
**Type:** Short Answer
**Question:** Klausa apa pada sintaks SQL yang digunakan untuk memfilter baris data berdasarkan kondisi tertentu (misalnya: hanya mengambil pengguna dengan umur > 20)?
**Answer:** WHERE.

### Q5
**Type:** Short Answer
**Question:** Perintah kombinasi SQL apakah yang digunakan untuk membuat struktur tabel baru di dalam database?
**Answer:** CREATE TABLE.
