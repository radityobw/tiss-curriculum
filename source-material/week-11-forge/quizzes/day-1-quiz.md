### Q1
**Type:** Multiple Choice
**Question:** Mengapa pengembang perangkat lunak (*developer*) sangat disarankan untuk membiasakan deklarasi variabel menggunakan `const` daripada `let` (terutama selama nilai variabel tersebut dirancang statis/tidak perlu diubah)?
- [ ] A. Karena penggunaan atribut tersebut memacu kecepatan CPU server menjadi dua kali lipat lebih cepat.
- [ ] B. Sebab atribut tersebut akan memotong ukuran teks fail koding sumber menjadi lebih kecil.
- [x] C. Penggunaan `const` menjamin integritas variabel dari penimpaan atau mutasi nilai yang tak disengaja, membantu mengamankan alur logika dan menekan risiko masuknya celah *bug*.
- [ ] D. Layanan peladen web senantiasa memaksa format tersebut untuk penulisan huruf kapital.

### Q2
**Type:** True/False
**Question:** Jika nilai angka ditulis dalam tanda kutip (misalnya `let umur = "25";`) lalu ditambahkan dengan angka lain menggunakan operator `+` (misalnya `umur + 5`), hasilnya akan dijumlahkan secara matematis menjadi 30.

### Q3
**Type:** Short Answer
**Question:** Jika HTML diibaratkan sebagai kerangka tubuh manusia dan CSS sebagai kulit/pakaian, maka JavaScript berperan sebagai apa?

### Q4

**Question:** Apa kata kunci deklarasi *variable* modern dalam JavaScript ES6 yang diizinkan agar nilai muatannya dapat diubah-ubah nilainya (*reassignable*) berulang kali?
