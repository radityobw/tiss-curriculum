### Q1
**Type:** Multiple Choice
**Question:** Apa perbedaan mendasar antara Git dan GitHub?
- [x] A. Git adalah perangkat lunak *version control* lokal yang diinstal di komputer untuk melacak perubahan kode, sedangkan GitHub adalah layanan *platform cloud hosting* internet untuk menyimpan repositori Git agar dapat dikolaborasikan secara global.
- [ ] B. GitHub adalah produk perangkat lunak *offline*, ketika Git adalah platform layanan internet *cloud*.
- [ ] C. Keduanya adalah hal yang sama persis tanpa perbedaan, diciptakan oleh perusahaan yang sama.
- [ ] D. Git diciptakan sebagai program pelacak *malware*, sedangkan GitHub adalah tempat pengujian kode .

### Q2
**Type:** True/False
**Question:** Dalam standar praktik kolaborasi industri, seorang kontributor kode (*developer*) tidak disarankan untuk langsung melakukan `git push` ke *main branch* (cabang utama), melainkan diwajibkan menggunakan sistem *Feature Branch* dan mengajukan *Pull Request* terlebih dahulu.
**Answer:** True

### Q3
**Type:** Short Answer
**Question:** Perintah Git apa yang secara spesifik digunakan untuk mengunduh dan menyinkronkan data pembaruan kode terbaru dari repositori *remote* (misalnya GitHub) menuju repositori lokal di komputer *developer*?
**Answer:** git pull.

### Q4
**Type:** Short Answer
**Question:** Apa istilah/akronim untuk fitur pengajuan perubahan kode di GitHub agar kode kita direviu dan digabungkan (*merge*) ke cabang utama oleh pemilik repositori?
**Answer:** Pull Request (PR).

### Q5
**Type:** Short Answer
**Question:** Fitur apakah di GitHub yang digunakan ketika seseorang ingin menyalin keseluruhan struktur repositori proyek *Open Source* milik entitas lain ke akun pribadinya, agar ia dapat memodifikasinya dengan leluasa tanpa perlu izin akses pada repositori aslinya?
**Answer:** Forking (Atau Fork).
