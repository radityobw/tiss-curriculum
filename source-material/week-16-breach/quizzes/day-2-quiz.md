### Q1
**Type:** Multiple Choice
**Question:** Membedah spesifikasi teknis tebakan eksploitasi taktik *SQLi* yang dipaksa bisu oleh pengamanan peladen antarmuka, parameter konseptual mendasar apakah yang membedakan klasifikasi *Blind SQLi* dibandingkan pengerahan taktik eksploitasi responsif tipe parameter *UNION-based SQLi*?
- [ ] A. *UNION SQLi* dirancang secara spesifik melacak penetrasi untuk meretas akun kredensial entitas *bot* peladen, sementara pemanfaatan *Blind SQLi* ditugaskan semata membajak parameter otentikasi token sesi otentik milik panel kendali admin situs sasaran.
- [ ] B. Spesifikasi pembentukan kueri arsitektur *Blind SQLi* secara struktural dilarang mutlak untuk memuat maupun menyertakan perikatan integrasi logika parameter Boolean peladen operator *AND/OR*.
- [x] C. Pada metode *UNION*, rincian pengikatan muatan ekstraksi ekstraksi data hasil pembongkaran arsip kueri tabel (semacam wujud payload lapor nama sandi *password*) niscaya terpampang muntah secara vulgar lantas dicetak visual pada laporan keluaran layar halaman muka antarmuka *Web*. Sebaliknya, pada eksekusi peladen yang terpapar celah peramban arsitektur *Blind SQLi*, parameter peladen niscaya ditekan dan dikonfigurasi pengamanan berstatus bisu meredam pengungkapan isi (*no data response/no error text*); memaksa penganalisis meraba lantas mengekstraksi konfirmasi deteksi kebocoran data rincian semata-mata mengandalkan parameter pemantauan rincian logika pelaporan parameter interaksi merespons observasi gelagat pembacaan kebenaran fungsi boolean *TRUE/FALSE* atau dengan mencermati waktu penahanan *loading* eksekutor peladen.
- [ ] D. Pelaksanaan operasional simulasi penetrasi arsitektur peladen pada *Blind SQLi* membutuhkan validasi persetujuan ekstensi analisis *Wappalyzer* agar dapat difungsikan pada terminal sasaran.

### Q2
**Type:** True/False
**Question:** Taktik eksekusi intelijen peretasan berbasis tebakan pengukuran perlambatan arsitektur waktu peramban fungsi eksploitasi tipe *Time-based Blind SQLi* mewajibkan fungsionalitas peretas untuk mengekstrak respons temuan parameter informasi kerentanan semata-mata dengan cara menuntut pembuktian formulasi pertanyaan kueri logika parameter boolean *TRUE/FALSE* matematika peladen yang lantas dieksekusi secara memaksa peladen mengangguk via pertanda pencetakan perenderan antarmuka halamannya (Layar bakal terpampang utuh normal bilamana tebakan diartikan benar/*TRUE*, sementara layar akan dicetak lenyap responsnya kosong bilamana kueri dinilai keliru/*FALSE*) tanpa sama sekali menyisipkan parameter kebutuhan analisis perlambatan parameter waktu nafas penahanan durasi eksekutor *query*.
**Answer:** False

### Q3

**Question:** Ketika meluncurkan serangan eksploitasi peramban analisis tipe tebakan *Boolean-based Blind SQLi*, formulasi penyisipan pelaporan payload fungsi tipe apa pada analisis pembuktian kueri evaluasi logika parameter dasar matematika sakti (berkemampuan membedakan klasifikasi pelaporan tebakan statis *True* atau respons gagal *False*) yang ditunggangi oleh spesialis peretas guna menebak lantas membongkar kerangka wujud rincian huruf payload arsip peladen selangkah demi selangkah?
**Answer:** Boolean.

### Q4
**Type:** Short Answer
**Question:** Di ranah operasi peretasan spesifik pengujian manipulasi pengujian kueri penahanan peramban waktu sasaran (*Time-based Blind SQL Injection*), pemicu payload delegasi parameter sandi instruksi penyisipan jeda eksekutor pembekuan proses peramban kompilator peladen jenis aplikasi basis data macam apakah yang acap kali lazim dipanggil disisipkan rute peretas menuju sistem kueri database peladen target demi membuktikan secara empiris kebenaran sintaks tebakan logis penyusup (misal contoh merancang perintah komando yang mensyaratkan server terdiam merenung membekukan rincian jeda pemuatan koneksi lambat pelaporan antarmuka penahan beban durasi nafas waktu terhitung *10 detik* eksekusi )?
**Answer:** SLEEP() (untuk peladen *MySQL/MariaDB*), atau varian parameter identik *pg_sleep()* (PostgreSQL), dan *WAITFOR DELAY* (di instalasi peramban logik MSSQL).
