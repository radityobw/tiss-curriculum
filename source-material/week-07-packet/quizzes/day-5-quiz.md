### Q1
**Type:** Multiple Choice
**Question:** Jenis eror apa yang terjadi ketika terminal mengeksekusi format perintah `cat spaces in this filename` saat kamu mencoba membuka nama file yang memuat banyak spasi di lab Linux?
- [x] A. Terminal membaca tiap spasi sebagai pembatas argumen perintah. Sehingga ia mengira diinstruksikan untuk membuka 4 nama file teks yang berbeda-beda, bukan satu file yang utuh (seharusnya diapit tanda kutip dua).
- [ ] B. Peranti Linux akan otomatis membatalkan seluruh operasi eksekusi file teks.
- [ ] C. Komputer segera menerjemahkan huruf kapital secara acak demi melindungi kerahasiaan direktori.
- [ ] D. Terminal langsung mengunci tampilan dan membutuhkan autentikasi ulang via jaringan internet.

### Q2
**Type:** True/False
**Question:** Saat kamu memasukkan kata sandi (login OS) di terminal Linux, layar akan menampilkan rentetan simbol asterisk bintang (`***`) untuk menunjukkan bahwa ketikan input di papan ketik telah diterima oleh server.
**Answer:** False

### Q3
**Type:** Short Answer
**Question:** Apa kepanjangan dari akronim komando jaringan terminal bernama `ssh` yang digunakan untuk otentikasi dan administrasi jarak jauh *server* yang terenkripsi aman?
**Answer:** Secure Shell.

### Q4
**Type:** Short Answer
**Question:** Nama situs simulator peretasan *wargame* daring legendaris di komunitas global apa, dengan jenjang kenaikan level *Capture the Flag*, yang dipergunakan sebagai basis misi latihan terminal Linux di minggu ini?
**Answer:** OverTheWire Bandit (Bandit Wargame).

### Q5
**Type:** Short Answer
**Question:** Komponen subsistem (lingkungan *runtime*) ciptaan Microsoft apakah yang disingkat menjadi 3 huruf untuk memungkinkan *environment* Kernel Linux beroperasi secara *native* berdampingan di OS dasar Windows?
**Answer:** WSL (Windows Subsystem for Linux).
