### Q1
**Type:** Multiple Choice
**Question:** Mengapa perintah `cat spaces in this filename` (tanpa tanda kutip) akan menghasilkan *error* saat mencoba membuka file yang namanya mengandung spasi?
- [x] A. Terminal membaca tiap spasi sebagai pemisah antar parameter. Sehingga ia mengira disuruh membuka 4 file berbeda, bukan satu file yang utuh (seharusnya diapit tanda kutip dua).
- [ ] B. Peranti Linux akan otomatis membatalkan seluruh operasi eksekusi file teks.
- [ ] C. Komputer segera menerjemahkan huruf kapital secara acak demi melindungi kerahasiaan direktori.
- [ ] D. Terminal langsung mengunci tampilan dan membutuhkan autentikasi ulang via jaringan internet.
