### Q1
**Type:** Multiple Choice
**Question:** Berpedoman pada arsitektur hierarki model tampilan (CSS Box Model), perbedaan teknis utama manakah yang secara memisahkan fungsi Margin dan Padding?
- [x] A. Margin digunakan untuk mengatur jarak (spasi kosong) di bagian LUAR elemen untuk memisahkannya dari elemen-elemen di sekitarnya. Sebaliknya, Padding digunakan untuk mengatur ruang kosong di bagian DALAM garis batas (*border*) elemen, yang memisahkan konten internal dengan batas kotaknya sendiri.
- [ ] B. Margin selalu memiliki properti transparansi warna, sedangkan Padding selalu mengikuti warna *background* dasar situs web secara mutlak.
- [ ] C. Margin digunakan untuk mengukur bobot ukuran file memori RAM, sedangkan Padding mengukur koordinat lokasi resolusi pixel.
- [ ] D. Keduanya memiliki fungsi yang sama persis dan saling menimpa satu sama lain saat proses perenderan *browser*.

### Q2
**Type:** True/False
**Question:** Ketika seorang penelaah keamanan keamanan (*pentester*) mencoba mengubah gaya tata letak halaman sebuah web (mengutak-atik properti *Elements*) melalui *Developer Tools* (F12) pada *browser*, perubahan tersebut otomatis melekat secara permanen di basis data server lokal mereka apabila halaman web tersebut dimuat ulang (*Refresh*).
**Answer:** False

### Q3
**Type:** Short Answer
**Question:** Di antarmuka jendela *Browser Developer Tools*, nama *tab* panel manakah yang difungsikan layaknya program penyadap mini untuk memantau, menelaah, dan menelusuri rincian struktur komunikasi perpindahan data atau paket API *HTTP Request/Response* ke server?
**Answer:** Tab Network.

### Q4
**Type:** Short Answer
**Question:** Di dalam hirarki pemilihan kelas modifikasi (CSS Selector), metode *selector* spesifik apakah (yang dinotasikan oleh simbol awalan pagar `#`) yang bersifat kaku dan diotorisasi penggunaannya untuk identifikasi gaya satu buah entitas elemen (unik) saja di halaman *markup*?
**Answer:** ID Selector.

### Q5
**Type:** Short Answer
**Question:** Sistem perancangan antarmuka penempatan *layout* modern di CSS apakah yang terkenal akan elastisitas fungsinya dalam mengakomodasi pembagian penyebaran kontainer baris maupun pilar susunan kolom tanpa lagi perlu bersusah-payah memakai *float* atau tabel konvensional?
**Answer:** Flexbox (Flexible Box).
